# オムニワイフ

A mix of projects I use for my personal assistant (self-deprecatingly - waifu) and tools / programs I use together. I primarily use linux so most of these are built with that assumption but willing to take PRs if you notice anything weird, I'm sure there's edge cases I've missed that are outside my workflow.

## projects

 * [dere/デレ](https://github.com/omniwaifu/dere) - main project I use - essentially a monorepo claude code wrapper that uses a daemon for embeddings, context injection, personality, etc. etc. - essentially the frontend for task management and general conversational stuff I do.
 * then various MCP servers I use with dere
 * some research tooling for taking notes with Obsidian/Zotero, etc.
 * experimentations with Live2D models
